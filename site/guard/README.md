# 게시 검사기

사이트 빌드(`npm run build`)가 내보내기 데이터(`data/site/`)를 읽기 전에 실행하는 검사기다. 표준 라이브러리만 쓰는 Python 3 스크립트다.

- `tools/validate.py <data/site 폴더>` — 형식(`schema/`)과 게시 규칙을 검사한다. 종료 코드 0 통과, 1 빌드 거부, 2 사용법 오류.
- `tools/test_validate.py` — 검사기 시험(`python3 -m unittest test_validate`, `tools/`에서).
- `tools/v1_to_export.py` — 기존 `data/*.json`을 내보내기 형식으로 바꿔 보는 시험용 변환기.

## 빌드 거부 규칙

1. 형식: 각 파일이 `schema/`의 형식과 맞지 않음.
2. 원천 흔적: 본문·제목에 주소, SNS 계정, 반응 수, 출처 표기 문구가 남아 있음.
3. 내부 운영 문구: 운영 식별자, 내부 용어, 운영자 1인칭 맥락.
4. 공식 링크: https가 아니거나 소셜·토론 주소이거나 리디렉트 매개변수가 있음.
5. 미디어: 경로가 올바르지 않거나(`--assets`를 주면) 파일이 없음.
6. 서로 맞지 않음: 색인과 호 파일, slug 중복, 대표 기사·세 줄·주간 호 선택, 덱과 본문 첫 단이 같음.
7. 영구성(`--previous`를 주면): 한 번 공개한 글의 주소가 사라짐.
8. 경고만(빌드는 계속): 비어 있는 설정 칸, 본문 빈 단 등.

전환 모드(내보내기 데이터가 아직 없을 때)는 이 검사를 건너뛰고, 화면 표시 직전에 원천 흔적을 가리는 정리만 한다.
